This repository contains the complete, production-grade, multi-page web application featuring 50+ optimized landing pages, a unified design system, advanced PWA (Progressive Web App) support, SEO metadata, JSON-LD Schema markup, and responsive UI components.

## ⚡ Key Technical Features & Capabilities

### 1. 📱 Full Progressive Web App (PWA) Integration
- **Web App Manifest (`manifest.json`):** Configured with standalone display mode, Gold (`#FFD700`) theme color, and dark background (`#0B0F19`).
- **Service Worker (`sw.js`):** Implements a **Network-First with Stale-While-Revalidate Fallback** strategy to ensure real-time content delivery when online and full offline availability when disconnected.
- **Automated PWA Prompts:** `global.js` includes custom modal listeners for Android Chrome PWA installation and specialized iOS Safari "Add to Home Screen" instructions.

### 2. 🎨 Unified Design System (`/assets/css/style.css`)
- **Primary Color:** Gold (`#FFD700` / `#D4AF37`) & Deep Charcoal (`#0B0F19` / `#1F2937`)
- **Typography:** Google Fonts (`Poppins` & `Open Sans`)
- **Mega Navigation:** 3-Column responsive mega dropdown menu for services with hover feedback.
- **Subpage Hero Standard (`.inner-hero`):** Uniform dark radial-gradient banner across all 50+ subpages featuring gold gradient typography, breadcrumbs, action buttons, and trust badges.
- **Hover Micro-Interactions:** Custom `.card-hover-effect` with gold glow borders and smooth lift transforms (`translateY(-8px)`).

### 3. 🔍 Comprehensive SEO & Crawling Infrastructure
- **Dynamic XML Sitemap (`sitemap.xml`):** Fully structured index listing all 50 landing pages with proper `<priority>`, `<changefreq>`, and `<lastmod>` attributes.
- **Robots Directive (`robots.txt`):** Configured for Googlebot, Bingbot, Yandex, DuckDuckBot, as well as AI crawlers (GPTBot, ClaudeBot, PerplexityBot, Google-Extended).
- **Open Graph & Twitter Cards:** Complete `<meta property="og:...">` tags on all pages for rich social media sharing.
- **Schema.org Structured Data:** JSON-LD declarations (`DigitalMarketingAgency`, `LocalBusiness`, `Organization`) for localized search snippet dominance in Pakistan.

## 💻 Server & Deployment Guide

The application runs on a Node.js Express server (`server.js`) configured for port **3000** with static compression.

### 🛠️ Local Development & Running
1. **Install Dependencies:**
   ```bash
   npm install
   ```
2. **Start Dev Server:**
   ```bash
   npm start
   ```
3. Open `http://localhost:3000` in your browser.
